# 🏛️ Software Engineering System Design Curriculum (LLD & HLD)

A production-grade, interview-ready curriculum covering **Low-Level Design (LLD)** and **High-Level Design (HLD) / Distributed Systems Architecture**, built with **Java 21 / Spring Boot 3**.

---

## 📂 Repository Structure

```
.
├── 1.LLD/                                     # Low-Level Design & Object-Oriented Design Patterns
│   ├── 0.Assets/                              # Visual diagrams, UML specifications
│   ├── 1.Fundamentals/                        # OOP Principles, SOLID Principles, Clean Code
│   ├── 2.Creational/                          # Factory, Builder, Singleton, Prototype
│   ├── 3.Behavioral/                          # Strategy, Observer, Command, State, Chain of Responsibility
│   ├── 4.Structural/                          # Adapter, Decorator, Facade, Proxy, Composite
│   └── 5.Concurrency-In-LLD/                  # Threads, Locks, Thread-safety, Producer-Consumer
│
└── 2.HLD/                                     # High-Level Design (12 Clean Modules)
    ├── 1.HLD-Fundamentals/                    # Request lifecycle, Monolith vs Microservices, Statelessness
    ├── 2.Networking-Basics/                   # DNS, HTTP/2 & HTTP/3, TCP vs UDP, TLS 1.3, CDN, Load Balancers
    ├── 3.Scalability/                         # Horizontal Scaling, Autoscaling, CAP & PACELC, Consistent Hashing
    ├── 4.Databases/                           # SQL vs NoSQL, Replication Lag, Sharding, B+ Tree vs LSM, Transactions
    ├── 5.Caching/                             # Cache-Aside, Redis Data Structures, LRU/LFU, Stampede/Avalanche Fixes
    ├── 6.Messaging-Systems/                   # Kafka Topics & Partitions, RabbitMQ, SQS, Idempotency, DLQs
    ├── 7.Storage-Systems/                     # S3 Object Storage, Pre-Signed Uploads, Multi-Part Chunking, CDN
    ├── 8.Microservices/                       # API Gateways, Circuit Breakers (Resilience4j), Bulkheads
    ├── 9.Security-And-Auth/                   # JWT, Access vs Refresh Tokens, OAuth2, Rate Limiting (Token Bucket)
    ├── 10.Observability/                      # 4 Golden Signals, Prometheus, Grafana, OpenTelemetry Traces
    ├── 11.Design-Tradeoffs/                   # Consistency vs Latency, Latency vs Throughput, Read vs Write Heavy
    ├── 12.Real-System-Design-Interviews/      # 9-Step Framework + Real Systems (WhatsApp, Uber, Netflix, TinyURL)
    └── README.md                              # HLD Navigation Map
```
